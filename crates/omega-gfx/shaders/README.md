LCD1x, LCD3x and Pixel Transparency sources: libretro/glsl-shaders @ ce9a41242e27f41e16bc35c28943466cee3e8ff8, handheld/. Original files retain upstream authorship/license notices. Adapters support cropped textures, native GLES2 bindings, selectable source palettes and a separate LCD raster for stretched GB/GBC. LCD+PT retains two passes and upstream defaults, except user-configurable shadow offsets (fork default 1).

pixel-grid.frag is the fork's physical 3x panel grid, with literal black row/column separators. Grid+PT fuses that mask into the real PT pass and exits on separators before expensive shading. It intentionally replaces lcd-grid-v2; the older source files remain as provenance, not active presets. palette.glsl supplies optional four-shade source styling; Game colours bypasses it. Saturation is a final game-only colour transform and does not affect UI.
