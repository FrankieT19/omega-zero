LCD1x, LCD3x and Pixel Transparency sources: libretro/glsl-shaders @ ce9a41242e27f41e16bc35c28943466cee3e8ff8, handheld/. Original files retain upstream authorship/license notices. Adapters support cropped textures, native GLES2 bindings, selectable source palettes and a separate LCD raster for stretched GB/GBC. LCD+PT retains two passes and upstream defaults, except user-configurable shadow offsets (fork default 1).

pixel-grid.frag is the fork's physical 3x panel grid, with literal black row/column separators. Grid+PT fuses that mask into the real PT pass and exits on separators before expensive shading. It intentionally replaces lcd-grid-v2; the older source files remain as provenance, not active presets. palette.glsl supplies optional four-shade source styling; Game colours bypasses it. Saturation is a final game-only colour transform and does not affect UI.

LCD1x/LCD3x also checked against libretro/slang-shaders @ e1d75632a205c70f14a4cc947c46d5abb7b3f7f1, handheld/lcd1x.slangp and lcd3x.slangp (single viewport pass, nearest filtering). Original Slang sources are included alongside the GLSL originals. The GLES adapters bound trigonometric phase to one source-pixel cell, avoiding large-angle precision differences; the copy and final blit use high precision. Stock sampling is the default. Optional LCD edge smoothing uses sharp bilinear sampling at source boundaries, with nearest filtering restored before Pixel Transparency. LCD darkness remains an explicit user adjustment. Grid follows source pixels except GB/GBC Stretch, which emulates the fixed GBA panel grid.

V6 supersedes the handwritten LCD adapters: lcd1x.generated.glsl and lcd3x.generated.glsl are compiler output from the original Slang source via glslang/SPIRV-Cross. The actual generated shader evaluates cached coefficients; lcd_mask.rs contains no handwritten LCD sine formula. Game sampling is nearest only. Mask origins include the full source crop offset. Plain LCD/Grid render directly in one pass. No LCD edge-smoothing option remains. See scripts/compile-lcd-slang.py and crates/omega-gfx/src/slang.rs for the reproducible compiler and bindings.
