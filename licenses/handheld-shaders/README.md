Fragment adapters change only API bindings, cropped texture addressing, pragma defaults and ES2 syntax. LCD+Pixel Transparency runs two viewport-sized passes in upstream preset order. LCD1x/LCD3x also checked against libretro/slang-shaders @ e1d75632a205c70f14a4cc947c46d5abb7b3f7f1, handheld/lcd1x.slangp and lcd3x.slangp (single viewport pass, nearest filtering). Original Slang sources are included alongside the GLSL originals. The GLES adapters bound trigonometric phase to one source-pixel cell, avoiding large-angle precision differences; the copy and final blit use high precision. Stock sampling is the default. Optional LCD edge smoothing uses sharp bilinear sampling at source boundaries, with nearest filtering restored before Pixel Transparency. LCD darkness remains an explicit user adjustment. Grid follows source pixels except GB/GBC Stretch, which emulates the fixed GBA panel grid.

V6 supersedes the handwritten LCD adapters: lcd1x.generated.glsl and lcd3x.generated.glsl are compiler output from the original Slang source via glslang/SPIRV-Cross. The actual generated shader evaluates cached coefficients; lcd_mask.rs contains no handwritten LCD sine formula. Game sampling is nearest only. Mask origins include the full source crop offset. Plain LCD/Grid render directly in one pass. No LCD edge-smoothing option remains. See scripts/compile-lcd-slang.py and crates/omega-gfx/src/slang.rs for the reproducible compiler and bindings.
