omega-zero UI

The kit omega-zero's menus are drawn from: pixel-art components rebuilt in HTML as the reference for each screen, before and while it is drawn on the device. Every shape is a sprite written pixel by pixel, every word lands on whole pixels, and every colour follows the backdrop colour the player picks in Settings › Background › Colour. The rules for adding to the kit are in assets/ui/README.md.

Foundation

The art pixel

foundation/tokens.css

One art pixel is --u, 2px: omega-zero draws its pixel art 2×2, so a 640×480 panel is 320×240 art pixels. Every size in every component is a whole number of them, and nothing is ever smoothed: sprites are shown with image-rendering: pixelated.

Sprites

foundation/pixel.js

A shape is written in its component as rows of colour keys, one character to an art pixel, and OmegaPixel.sprite() paints it. A shape that must fit any size is a 9-slice: only its top-left quarter is drawn, mirror() makes the rest, and its corners stay as drawn while its edges stretch.

const CORNER = [       // omega-modal's frame
  '...kk',             // k dark, H bright, s stripe,
  '.kkHH',             // A frame colour, . nothing
  '.kHss',
  'kHsAA',
  'kHsAA',
];

Type

foundation/fonts.css

Pixel Code Regular at 18px, one face pixel to an art pixel, on a 20px line so its capitals sit on whole pixels. Pixel Code Bold is fattened off the grid, so it is not used: bold is drawn by setting the word again one pixel to the right. Bigger words (an action's label) are drawn into a sprite with OmegaPixel.letters() and stretched there, never with a CSS transform.

Backdrop

.omega-backdrop

The shelf's Grid: a 1 art pixel line every 20, in the backdrop colour lifted 9% toward white, drifting left 16px a second with data-moving, as crates/omega-ui/src/backdrop.rs draws it.

Colour

foundation/palette.js

The palette is made from the backdrop colour. Its ramp is Mega Man Zero's own menu colours, which is what Amber gives; any other colour keeps how light each step is and turns the ramp to its own hue, taking as much colour as it has itself. Night, the default, gives plain greys. OmegaPalette.apply(name) sets these properties and every component draws itself again. The swatches follow the colour picked above.

Components

<omega-modal>

components/omega-modal.js

The menu window and nothing else: a double-lined frame that stacks what it is given top to bottom. It knows nothing of what it holds; usually that is <omega-panel>s, which grow to share its height and share one stripe where they meet. It fills the box the page gives it.

APIWhat it does
slotAnything, stacked top to bottom. Give a child a bigger flex-grow (or a flex-basis in whole art pixels) to make it taller.
::partframe, content
<omega-modal>
  <omega-panel label="BUTTON SETTING" active></omega-panel>
  <omega-panel label="ATTACK MODE"></omega-panel>
</omega-modal>

<omega-panel>

components/omega-panel.js

A titled section for inside a modal: a dark tab with the title from its left edge and a slanted end, the bright strip beside it, and a well below for the content.

<action-left>

components/action-left.js

The bottom bar's left action: a return arrow in a notch at the screen's edge, a big label, and a button pill with a hint. 21 art pixels tall; the notch rises 6 above it. Without attributes it is empty, with room kept for its label.
